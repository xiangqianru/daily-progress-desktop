每日进度 v1.1.0
================

一、运行环境

支持 Windows 10 和 Windows 11。程序为便携版，无需安装。
如果系统提示缺少运行组件，请在 Windows 功能中启用 .NET Framework 4.x。

二、开始使用

1. 解压整个压缩包。
2. 双击“每日进度.exe”。
3. 首次启动会显示每日任务和长期任务示例，均可编辑或删除。

本程序尚未进行商业数字签名。从互联网下载后，Windows 可能显示安全提示；
请先核对发布页面提供的 SHA-256，再选择运行。

三、主要功能

- 每日必做：支持每天、工作日和自定义星期，次日自动生成。
- 完成型任务：支持截止日期、优先级、状态、分步进度、手动排序和完成归档。
- 手动排序：使用任务卡片右上角的“↑ / ↓”调整顺序，重启后仍会保留。
- 三套主题：海盐蓝、樱花粉、森野绿，标题栏和悬浮提醒同步换肤。
- 农历与黄历：离线显示农历及传统民俗宜忌，仅供日常参考。
- 后台提醒：支持系统托盘、开机启动和桌面悬浮提醒。

四、托盘与悬浮提醒

主界面左下角“提醒设置”可以控制：

- 开机自动启动；
- 程序启动后自动隐藏；
- 关闭或最小化时隐藏到系统托盘；
- 桌面悬浮提醒是否显示和置顶。

隐藏到托盘后，双击 Windows 右下角“每日进度”图标可恢复主界面；
右键图标可以显示或隐藏悬浮提醒，也可以彻底退出程序。

五、数据与升级

任务数据保存在：

%LOCALAPPDATA%\DailyProgressDesk\tasks.json

同目录的 tasks.json.bak 是最近一次备份。升级时只需退出程序并替换 EXE，
任务数据不会随程序文件一起删除或覆盖。

六、卸载

1. 如果启用了开机启动，请先在“提醒设置”中取消勾选。
2. 从系统托盘右键选择“退出每日进度”。
3. 删除程序文件夹。
4. 如需同时清除个人任务，再删除：
   %LOCALAPPDATA%\DailyProgressDesk

删除数据目录后无法恢复，请自行确认或提前备份。
