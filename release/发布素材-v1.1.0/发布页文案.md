# 每日进度 v1.1.0

一款简洁、离线、无需安装的 Windows 桌面任务工具，把“每天必须完成的事”和“完成后即可归档的长期任务”放在同一个页面中管理。

## v1.1.0 更新

- 新增完成型任务手动排序：点击任务卡片上的 `↑ / ↓` 调整顺序，自动保存。
- 修复窗口放大后再缩小时，完成型任务可能排成多列、部分卡片被裁切的问题。
- 修复任务详情步骤列表缩放后的纵向滚动范围。

## 功能亮点

- 每日必做：运动、喝水、阅读等事项每天自动出现。
- 完成型任务：专利、文章、投稿等任务可拆成步骤，准确计算完成百分比。
- 三套主题：海盐蓝、樱花粉、森野绿，标题栏和悬浮提醒一起换肤。
- 桌面提醒：可拖动的悬浮助手显示今日剩余任务，点击即可打开主界面。
- 后台运行：支持开机启动、系统托盘以及关闭或最小化到托盘。
- 农历信息：离线显示农历和传统民俗宜忌。
- 完全离线：无需账号、不含广告、不上传任务数据。

## 下载与运行

下载 `每日进度-v1.1.0-Windows-便携版.zip`，解压后双击 `每日进度.exe`。

支持 Windows 10/11，需要系统启用 .NET Framework 4.x。程序当前未进行商业数字签名，首次运行可能出现 Windows 安全提示，请先核对发布页提供的 SHA-256。

## 升级说明

先从系统托盘退出旧版本，再用新版本替换原 EXE。任务数据保存在 `%LOCALAPPDATA%\DailyProgressDesk`，升级程序不会覆盖任务数据；建议升级前备份 `tasks.json`。

## 隐私

所有任务和设置只保存在本机 `%LOCALAPPDATA%\DailyProgressDesk`，程序不包含登录、广告、遥测或后台联网功能。
