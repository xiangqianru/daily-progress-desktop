# 每日进度

当前公开版本：**v1.1.0**

一个无需联网、无需安装运行环境的 Windows 桌面任务程序，支持两类任务：

- **每日必做**：每天、工作日或自定义星期自动出现；当天勾选，次日重新生成。
- **完成型任务**：长期保留，支持截止日期、优先级、状态、子步骤、手动排序和完成归档。
- **三套外观主题**：海盐蓝、樱花粉、森野绿；主页面、详情页和操作窗口统一换肤。
- **后台提醒**：支持开机启动、启动后最小化、关闭或最小化到系统托盘。
- **桌面悬浮助手**：显示今日剩余任务数，可拖动、置顶，点击即可恢复主界面。

## v1.1.0 更新

- 完成型任务卡片新增 `↑ / ↓` 手动排序，调整后自动保存，重启仍保持顺序。
- 修复主窗口放大后再缩小时，完成型任务可能排成多列并被裁切的问题。
- 同步修复任务详情步骤列表在窗口缩放后的纵向滚动范围。

## 直接使用

双击 `dist\每日进度.exe` 即可运行。

首次启动会提供“运动 30 分钟”“喝水 2000 ml”和一个专利申请示例，均可编辑或删除。

数据自动保存在：

```text
%LOCALAPPDATA%\DailyProgressDesk\tasks.json
```

同目录会保留最近一次数据备份 `tasks.json.bak`。应用升级或移动 EXE 不会丢失数据。

## 外观主题

在主页面左下角点击“外观”，可以随时选择海盐蓝、樱花粉或森野绿。主题选择会自动保存，下次打开仍会使用上次的配色。

## 提醒与后台运行

在主页面左下角点击“提醒设置”，可以分别控制开机启动、程序启动后自动隐藏、
关闭按钮或最小化按钮是否隐藏到托盘，以及悬浮助手是否显示和置顶。

程序隐藏到托盘后，双击 Windows 右下角的“每日进度”图标可以恢复主界面；
右键图标可以显示或隐藏悬浮提醒，也可以彻底退出程序。悬浮助手会显示今日完成数，
可以拖动到任意屏幕，位置会自动保存。

## 桌面快捷方式

运行 `创建桌面快捷方式.ps1`，即可在 Windows 桌面创建“每日进度”快捷方式。如果程序被移动过，也可以传入新的 EXE 位置：

```powershell
.\创建桌面快捷方式.ps1 -ExePathOverride 'D:\应用\每日进度.exe'
```

## 重新构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

程序使用 Windows 自带的 .NET Framework WinForms，不需要下载 NuGet 包或安装 .NET SDK。

应用图标源文件位于 `assets\daily-progress-icon.png`，构建时使用多尺寸的
`assets\daily-progress.ico` 嵌入 EXE 和窗口标题栏。

主界面显示农历和简版黄历宜忌。2020–2040 年数据由项目内的
`tools\generate_almanac.py` 使用 `lunar-python` 1.4.8 离线生成并嵌入 EXE；
运行程序不需要联网。黄历宜忌属于传统民俗信息，仅供日常参考。

## 公开分享

对外发布时只需分发 `dist\每日进度.exe`，不要打包个人的
`%LOCALAPPDATA%\DailyProgressDesk` 数据目录。建议同时附上本说明、界面截图、
版本号和 SHA-256 校验值。当前 EXE 未进行商业代码签名，其他电脑首次下载运行时
可能出现 Windows 安全提示；正式大范围发布可再增加数字签名和安装包。
